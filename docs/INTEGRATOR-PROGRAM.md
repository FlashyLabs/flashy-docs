# Flashy Integrator Program

A three-tier program for companies building with the Flashy ecosystem. From community contributors to strategic partners.

---

## Program Tiers

### 🔓 Community Tier (Free)

For developers, small teams, and projects using Flashy.

**Requirements:**
- Public GitHub repository using Flashy
- At least 1 working integration (code + tests)
- Documentation linking to flashy-examples and flashy-docs
- Commit to open-source licensing (Apache 2.0, MIT, GPL, etc.)

**Benefits:**
- ✅ Listed in Flashy Integrations directory (public)
- ✅ GitHub "Powered by Flashy" badge
- ✅ Community support via GitHub Issues/Discussions
- ✅ Feature requests on our roadmap (prioritized with others)
- ✅ Early access to beta features
- ✅ Monthly newsletter mention (projects of the month)

**Process:**
1. Build your integration
2. Publish code + tests on GitHub
3. File an issue in `flashy-examples` with:
   - Repository URL
   - Description (2-3 sentences)
   - Use case
   - Link to documentation
4. We'll review and add you to the directory

**SLA:** 48-hour response time on critical issues

---

### ⭐ Standard Tier (Paid)

For companies building production systems with Flashy.

**Requirements:**
- All Community Tier requirements, plus:
- Minimum 10K monthly transactions (measured)
- Dedicated technical contact
- Production-ready deployment (monitored)
- Security audit passed (annual)
- Uptime commitment (99% SLA)

**Benefits:**
- ✅ Everything in Community Tier, plus:
- ✅ **Dedicated support channel** (Slack or email)
- ✅ **Priority feature requests** (fast-tracked)
- ✅ **Early access to new packages** (beta, alpha)
- ✅ **Co-marketing** (case study, blog post, joint webinar)
- ✅ **Technical consulting** (4 hours/month included)
- ✅ **Custom deployment guidance** (2 sessions/month)
- ✅ Security bulletins (48h advance notice)
- ✅ Quarterly business review

**Benefits value:** ~$5K/month (consulting equivalent)

**Cost:** $499/month (paid annually: $5,388)

**Process:**
1. Meet requirements (provide metrics)
2. Sign partner agreement
3. Join private Slack channel
4. Attend onboarding call
5. Begin monthly reviews

**SLA:**
- P0 (service down): 1-hour response, 4-hour resolution
- P1 (degraded): 4-hour response, 24-hour resolution  
- P2 (feature/docs): 48-hour response

---

### 🏆 Strategic Tier (Enterprise)

For mission-critical integrations and long-term partnerships.

**Requirements:**
- All Standard Tier requirements, plus:
- Minimum 100K monthly transactions
- Multi-year commitment (2 years minimum)
- Joint product roadmap alignment
- Quarterly strategy meetings
- Dedicated account manager

**Benefits:**
- ✅ Everything in Standard Tier, plus:
- ✅ **Dedicated account manager**
- ✅ **Custom SLA** (99.95% or higher)
- ✅ **Priority bug fixes** (within 24h for critical)
- ✅ **Joint roadmap planning** (your features on our roadmap)
- ✅ **Co-branded assets** (shared go-to-market)
- ✅ **Speaking opportunities** (conferences, webinars)
- ✅ **Custom training** (for your team)
- ✅ **Private releases** (features built for you)
- ✅ **Security review** (quarterly, at no charge)
- ✅ **Technical consulting** (unlimited, dedicated engineer)

**Benefits value:** $50K+/month (custom services)

**Cost:** Custom pricing based on:
- Monthly transaction volume
- Number of engineering resources
- Custom development needs
- Infrastructure scale

**Process:**
1. Contact [partnerships@flashylabs.com](mailto:partnerships@flashylabs.com)
2. Executive alignment call
3. Custom proposal based on needs
4. Negotiate contract (typically 2-year term)
5. Dedicated account manager assignment

**SLA:**
- P0: 30-minute response, 2-hour resolution
- P1: 1-hour response, 8-hour resolution
- P2: 4-hour response, 48-hour resolution

## Application Process

### Community Tier

Send an issue to [flashy-examples](https://github.com/flashylabs/flashy-examples/issues/new) with:

```markdown
# [INTEGRATOR] Your Company Name

## Repository
https://github.com/yourorg/your-repo

## Description
Brief description of what you built (2-3 sentences).

## Use Case
What problem does this solve?

## Documentation
Link to your integration docs.

## Metrics
- Monthly users: X
- Monthly transactions: Y  
- Live since: YYYY-MM-DD
```

**Response time:** < 1 week

---

### Standard Tier

1. Email [partnerships@flashylabs.com](mailto:partnerships@flashylabs.com) with subject: `[INTEGRATOR] Standard Tier Application`

2. Provide:
   - Company background (founding date, funding, team size)
   - Integration overview (what you built)
   - Usage metrics (users, transactions, growth)
   - Technical contact (name, email, GitHub)
   - Product roadmap (what's next?)
   - Deployment status (staging vs. production)

3. We'll review within 2 weeks

4. Call to discuss partnership

5. Sign agreement

---

### Strategic Tier

1. Email [partnerships@flashylabs.com](mailto:partnerships@flashylabs.com) with subject: `[INTEGRATOR] Strategic Tier Inquiry`

2. Include:
   - Executive summary (vision + goals)
   - Company profile (size, stage, funding)
   - Transaction volume (current + 2-year projection)
   - Business model (how you monetize)
   - Technical team depth
   - Custom requirements (what features?)

3. Executive call scheduled (within 1 week)

4. Custom proposal created

5. Negotiate terms

6. Partnership begins

## FAQs

**Q: Do I need permission to build with Flashy?**
A: No. Build freely. Tell us about it so we can support you and list it in the directory.

**Q: Can I charge money for my integration?**
A: Yes. Community and Standard tiers can be for-profit. Strategic tier partners must align on terms.

**Q: What if I want to switch tiers?**
A: Upgrade anytime. Downgrade after contract term ends.

**Q: Do you invest in partner companies?**
A: No. Flashy doesn't take equity. Partnerships are commercial (we provide services).

**Q: What if I want to use Flashy but keep my code private?**
A: You can build privately. Community Tier requires public code, but you're free to build. Contact us about enterprise/private integrations.

**Q: How long does the approval process take?**
A: Community (1 week), Standard (2 weeks), Strategic (4 weeks).
